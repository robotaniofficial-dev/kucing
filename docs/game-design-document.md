# Kucing Adventure - Game Design Document

## Ringkasan
Kucing Adventure adalah game petualangan 2D yang mengikuti perjalanan seekor kucing menjelajahi dunia, mengumpulkan item, menyelesaikan misi, dan membuka area baru.

## Genre
- Adventure
- Platformer
- Casual

## Target Platform
- Web
- Android
- Desktop

## Core Gameplay
1. Pemain mengontrol seekor kucing.
2. Menjelajahi level dan area.
3. Mengumpulkan ikan, koin, dan item spesial.
4. Menyelesaikan quest dari NPC.
5. Membuka kemampuan baru.

## Sistem Progression
- XP dan level.
- Unlock skill.
- Unlock area.
- Koleksi item.

## Fitur MVP
- Gerakan karakter.
- Sistem kamera.
- Koin dan item collectible.
- NPC sederhana.
- Sistem quest dasar.
- Save game.

## Roadmap
