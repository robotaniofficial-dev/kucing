# Kucing Adventure 🐱

Kucing Adventure adalah game petualangan 2D berbasis browser dan Android.

## Target Platform
- Desktop Browser
- Mobile Browser
- Android (Capacitor)

## Stack
- React
- Phaser 3
- TypeScript
- Vite
- TailwindCSS
- Zustand
- Supabase
- Capacitor

## Status
Project berada pada tahap First Playable Build.
